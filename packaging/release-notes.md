## How to install
1. Download the zip below and **extract it** (right-click, Extract All). Don't run it from inside the zip.
2. Open the extracted folder and run **Just Serves.exe**.

## Windows warning
Windows may say "Windows protected your PC" because the app isn't code-signed.
Click **More info**, then **Run anyway**.

## Your data
Serves are saved on your own computer in a folder called `.justServes` in your user folder. Nothing is uploaded anywhere.
